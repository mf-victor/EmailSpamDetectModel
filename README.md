
# Email Spam Detector Model

مدل شناسایی ایمیل اسپم

## فایل ها
دیتاست استفاده شده برای این مدل `email_dataset.csv` 

فایل اصلی مدل:
`Model.py`

## اطلاعات اولیه 
* نوع مدل **Logistic-Regression** 
* دیتاست ترکیبی از داده واقعی و شبیه سازی شده
* میزان دقت مدل %99.68 است
* 80% سهم داده برای اموزش و 20% سهم داده برای آزمون(تست)


## دیتاست
نوع دیتاست **ترکیبی** است:


| منبع             | تعداد                                                                | 
| ----------------- | ----------------------------------------------------------------- |
| شبیه سازی شده توسط هوش مصنوعی | 5200 عدد  |
| واقعی | 1000 عدد ایمیل واقعی فارسی(500 عدد عادی و 500 عدد اسپم)|
|    مجموع    |6200 عدد ایمیل(3100 عدد عادی و 3100 عدد اسپم)



##  چطور متن تمیز شده؟  `cleaning` 

| گام | کار | چرا |
|---|---|---|
| ۱ | لینک ← `لینک` ، ایمیل ← `نشانیمیل` ، موبایل ← `شمارهتلفن` ، مبلغ ← `مبلغپول` ، درصد ← `درصدسود` ، عدد بلند ← `عددبلند` | این اقلام خودشان نشانهٔ اسپمند؛ حذف = اتلاف سیگنال، نگه‌داشتن عینشان = میلیون ویژگی بی‌مصرف |
| ۲ | `!` ← `علامتتعجب` ، کلمهٔ لاتین ← `حرفلاتین` | دو نشانهٔ قوی که گام ۴ نابودشان می‌کرد؛ پس از پیش نجات داده می‌شوند |
| ۳ | `ي→ی` ، `ك→ک` ، `أإآ→ا` ، `ة→ه` ، حذف نیم‌فاصله | «می‌شود»، «می شود» و «ميشود» باید یک واژه دیده شوند |
| ۴ | نگه‌داشتن فقط حروف فارسی | عدد خام، حروف لاتین و علامت‌گذاری نویزند |
| ۵ | حذف کشیدگی `ـ` و فشردن حروف تکراری | خنثی‌کردن ترفند فرار از فیلتر: «جااایزه» ، «تبرــیک» |
| ۶ | یکی‌کردن جمع و مفرد («جایزه‌ها» ← «جایزه») | واژگان کوچک‌تر و تعمیم بهتر |
| ۷ | جمع کردن فاصله‌ها | متن یکدست برای توکن‌سازی |


##  نتایج و ماتریس درهم‌ریختگی

تقسیم 80٪ آموزش (۴۹۶۰) و 20٪ آزمون (۱۲۴۰) .



**فاصلهٔ آموزش و آزمون = ۰٫۰۰۲۰** ← مدل  (overfit) ندارد.

**ماتریس درهم‌ریختگی (۱۲۴۰ ایمیل آزمون):**

|  | پیش‌بینی: عادی | پیش‌بینی: اسپم |
|---|---|---|
| **واقعی: عادی** | TN = 638 | FP = **0** |
| **واقعی: اسپم** | FN = 2 | TP = 600 |

- **FP = ۰** → حتی یک ایمیل عادی هم به پوشهٔ اسپم نرفته؛ مهم‌ترین خطا در فیلتر ایمیل همین است.
- **FN = 2** → فقط ۴2 اسپم از فیلتر رد شده.

## نقاط قوت مدل

* دقت بالای مدل(99%)
* صفر خطای مزاحم: هیچ ایمیل عادی ای اشتباها اسپم نشده
* مقاوم در برابر ترفند های فرار از فیلتر: اگر کلمه ای مثل رایگان اسپم باشه مدل رای**گان و رای-گان و سایر مقاومت هارو هم نیز اسپم میگیره
* داده ها ترکیبی از اسپم و عادی | واقعی و شبیه سازی شده مشابه واقعی هستند

## نقاط ضعف مدل

* اگر کل داده واقعی شود(تمام 6000 عدد)  درصد دقت به 4 الی 7 درصد کم تر کاهش می یابد
